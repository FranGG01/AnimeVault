# 🎬 AnimeVault

**Discover, explore and organize your anime universe.**

AnimeVault is a web application built with React and JavaScript that allows users to discover anime, explore rankings, search for titles and filter results by genre.

The project is currently under active development, with plans to introduce personal anime collections, user ratings and watchlists.

## 🚀 Features

- Browse anime with real information and cover images.
- Explore top-rated anime.
- Search anime by title within the currently loaded results.
- Filter anime by genre.
- Sort anime by rating or release year.
- Navigate through paginated anime results.
- Responsive interface with a modern dark theme.

## 🛠️ Tech Stack

- **React** — User interface and reusable components.
- **JavaScript** — Application logic.
- **Vite** — Development environment.
- **CSS3** — Styling and responsive design.
- **Tenrai API** — Anime information, ratings and images.


AnimeVault is a personal portfolio project currently under development, focused on improving React, JavaScript, API integration and frontend development skills.
